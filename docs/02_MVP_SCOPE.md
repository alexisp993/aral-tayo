# TaraLearn MVP Scope

## In scope
### Student experience
- Student app shell
- Home dashboard
- Subjects listing
- Subject detail
- Lesson overview
- Learn mode
- Flashcards
- Interactive practice
- Quiz
- Results
- Progress
- Achievements
- AI Tutor
- Student profile basics

### Activity types
1. Multiple choice
2. Drag and drop
3. Match pairs
4. Sort and categorize
5. Tap / hotspot

### Platform
- Responsive web application
- Desktop-first implementation matching supplied mockups
- Tablet/mobile adaptation without redesigning information hierarchy
- Authentication
- Persisted progress
- Persisted attempts
- Persisted XP/achievements
- Seed curriculum/content

## Architecture-only / future-ready
- Parent/student relationship
- Parent role
- Teacher role
- Admin role
- Multiple curriculum versions

## Explicitly out of MVP
- Calendar functionality
- Messages functionality
- Teacher dashboard
- Admin CMS
- Payments/subscriptions
- Multiplayer
- Social feeds
- Classroom leaderboards
- Live classes
- School/LMS integrations
- Advanced adventure/boss-battle games
- Native mobile apps

## Acceptance condition
The MVP is complete when a seeded Grade 5 learner can sign in and complete the full Adding Fractions learning journey, with progress, mastery, XP, achievements, and AI Tutor context persisted correctly.
